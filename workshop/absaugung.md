#### Hammer A3‑41 – Abricht- & Dickenhobel

| Parameter | Wert |
|---|---|
| Rohr | 140 mm |
| Schlauch | max. 30–40 cm |
| Schieber | Pflicht |
| Priorität | **Höchste** – Leitung möglichst frei halten |

#### Ulmia Tischkreissäge

- **Untertisch** → AF14 (140 mm), eigener Abgang mit Schieber
- **Oberabsaugung** → ❌ nicht an AF14, stattdessen System B (50–60 mm)

#### Bandsäge

- **Untere Absaugung** → AF14 (140 mm)
- **Obere Führung** → optional über System B

#### Langlochbohrmaschine

- **Rohr:** 140 mm an AF14
- Späneauswurf direkt am Bohrwerk
- Schieber: Pflicht

#### Frästisch (Untertisch)

- Durchmesser: 120–140 mm
- Nur an AF14 anschließen, wenn **exklusiv geöffnet** (alle anderen Schieber zu)

#### Schleiftisch (in Werkbank)

- **Einbau:** In die Werkbank integriert (bündige Oberfläche)
- **Rohr:** 140 mm direkt an AF14
- Absaugung von oben durch Lochplatte / Gitter + von unten durch Kasten
- Antistatische Schläuche empfohlen
- Schieber: Pflicht

#### Band‑/Tellerschleifer

- **Rohr:** 140 mm direkt an AF14
- Stationäres Gerät an der Werkbank
- Antistatische Schläuche empfohlen (Schleifstaub)
- Schieber: Pflicht

#### Kappsäge (äußere grobe Absaugung)

- **Rohr:** 140 mm direkt an AF14
- **Haube / Fangkorb** hinter/unter der Säge, fängt den Großteil der Späne auf
- Schieber: Pflicht
- Wird zusammen mit der integrierten Absaugung (System B) bei Maschinenstart geöffnet

## System B – Sauger + Zyklon

### Angeschlossene Maschinen & Punkte

Diese werden **ausschließlich** über das Saugersystem betrieben:

| Maschine / Punkt | Durchmesser | Besonderheiten |
|---|---|---|
| Frästisch (Anschlag) | 32–36 mm | Ergänzung zur AF14-Untertisch-Absaugung |
| Ulmia TKS (Oberabsaugung) | 50–60 mm | Nicht an AF14 |
| Bandsäge (obere Führung) | 32–36 mm | Optional |
| Standbohrmaschine | 32–36 mm | – |
| Kappsäge (integrierte kleine Absaugung) | 32–36 mm | Werksseitiger Anschluss, äußere Absaugung via AF14 (A8) |
| Bodensaugpunkt (unter Werkbank) | 50 mm | Bodenniveau unter Werkbank, dicht schließend |
| Schwenkarm | 32–36 mm | Antistatisch, zugfrei für Handgeräte |

### Details zu einzelnen Anschlüssen

#### Kappsäge – integrierte kleine Absaugung

- **Integrierte Absaugung (32–36 mm):** Werksseitiger Anschluss am Schutzgehäuse, für Feinstaub
- Die **äußere grobe Absaugung (140 mm)** läuft über System A / AF14 (→ A8)
- Beide Punkte (A8 + B5) werden bei Maschinenstart gleichzeitig geöffnet

#### Bodensaugpunkt – unter der Werkbank

- Einbau auf **Bodenniveau direkt unterhalb der Werkbank**
- Verschluss **dicht schließend** (Klappe oder Schieber)
- Kein Dauerleck im System
- Dient zum Aufsaugen von Spänen/Staub rund um den Werkbankbereich

#### Schwenkarm (Absaugung & Kabelmanagement)

- **Montage:** Am zentralen Pfosten in der Werkstattmitte (um den herum die großen Maschinen stehen)
- Schlauch: 32–36 mm, antistatisch
- Reichweite: zugfrei für Handgeräte, deckt den Bereich zwischen den großen Maschinen ab
- Einsatz: Exzenterschleifer, Deltaschleifer, leichte Fräsarbeiten
- Vorteil: Zentrale Position ermöglicht Absaugung an jeder Maschine für Handschleifarbeiten

## Automatisierte Absperrschieber – Siemens S7‑300

### Ziel

Jeder Absperrschieber wird über pneumatische oder elektrische Aktuatoren motorisch betätigt und durch eine **Siemens S7‑300 SPS** gesteuert. Nur der jeweils aktive Abgang öffnet sich — alle anderen bleiben geschlossen. Das maximiert die Saugleistung und verhindert Bedienfehler.

### Warum S7‑300?

| Vorteil | Detail |
|---|---|
| Industriestandard | Bewährt, robust, für 24/7‑Betrieb ausgelegt |
| Gebraucht günstig | Alte S7‑300 CPUs + Baugruppen ab ~50 € verfügbar |
| Erweiterbar | Digitale & analoge Ein‑/Ausgabebaugruppen modular steckbar |
| Deterministische Zykluszeit | Zuverlässiges Schaltverhalten, kein WLAN‑Ausfall |
| Home Assistant Anbindung | Via Ethernet‑CP (CP 343‑1) oder S7‑Connector / Snap7 |

### S7‑300 – Minimale Hardwarekonfiguration

### SPS‑Programmlogik (Ablaufbeschreibung)

```
┌─────────────────────────────────────────────────────┐
│  ZYKLISCH (OB1)                                     │
│                                                     │
│  1. Not‑Aus prüfen (E 1.2)                          │
│     → Wenn aktiv: ALLE Ausgänge AUS, Störmeldung    │
│                                                     │
│  2. Stromsensoren lesen (E 0.0 – E 1.0)             │
│     → Aktive Maschine(n) ermitteln                  │
│                                                     │
│  3. Schieber‑Logik:                                 │
│     a) System A: Zugehörigen Schieber ÖFFNEN        │
│        - Wenn A5 (Frästisch): ALLE anderen A‑       │
│          Schieber SCHLIESSEN (Exklusivmodus)        │
│        - A6 (Schleiftisch): normal öffnen           │
│        - A7 (Bandschleifer): normal öffnen          │
│        - A8 (Kappsäge äußere): + B5 koppeln        │
│     b) System B: Zugehörigen Schieber ÖFFNEN        │
│        - Gekoppelte Schieber (B1↔A5, B2↔A2,        │
│          B3↔A3, A8↔B5 Kappsäge) gleichzeitig       │
│                                                     │
│  4. Absaugung starten:                              │
│     → System A aktiv? → AF14 EIN (A 1.7)            │
│     → System B aktiv? → Sauger EIN (A 2.0)          │
│                                                     │
│  5. Abschaltverzögerung:                            │
│     → Kein Strom > 5 s → Schieber ZU                │
│     → Kein Schieber offen > 10 s → Absaugung AUS    │
│                                                     │
│  6. Endlagen überwachen:                            │
│     → Schieber angesteuert aber keine Endlage       │
│       nach 3 s → Störmeldung (A 2.1)                │
│                                                     │
│  7. Manuelle Taster (B6 Boden, B7 Schwenkarm):      │
│     → Tastendruck → Schieber toggeln + Sauger EIN   │
└─────────────────────────────────────────────────────┘
```

### Home Assistant Anbindung (optional)

Über den **CP 343‑1** Ethernet‑CP oder bei einfacheren CPUs via **Snap7**‑Gateway (Raspberry Pi als Brücke):

```yaml
# Home Assistant – configuration.yaml
siemens_s7:
  host: 192.168.1.50      # IP der S7-300 / CP 343-1
  rack: 0
  slot: 2
  entities:
    - name: "Schieber A1 – Hammer"
      address: A0.0
      type: digital_output
    - name: "Strom Hammer"
      address: E0.0
      type: digital_input
    # ... weitere E/A analog
```

Alternativ: **Node‑RED** mit `node-red-contrib-s7` als Middleware.

### Automatisierungsszenarien

| Szenario | Auslöser (SPS‑Eingang) | Aktion (SPS‑Ausgang) |
|---|---|---|
| **Maschine einschalten** | Stromsensor → E 0.x = 1 | Zugehörigen Schieber öffnen, AF14/Sauger starten |
| **Maschine ausschalten** | Stromsensor → E 0.x = 0 > 5 s | Schieber schließen, nach Nachlaufzeit (10 s) Absaugung stoppen |
| **Exklusivmodus A5** | E 0.4 (Frästisch) = 1 | A 0.0–A 0.3, A 0.5–A 0.7 schließen, nur A 0.4 offen |
| **Kappsäge Kopplung** | E 1.0 (Kappsäge) = 1 | A8 (AF14, 140 mm) + B5 (Sauger, integriert) gleichzeitig öffnen |
| **Manuell** | Taster E 1.3 / E 1.4 | Bodensaugpunkt / Schwenkarm toggeln |
| **Notfall** | Not‑Aus E 1.2 = 0 | ALLE Ausgänge AUS, Störmeldung A 2.1 |
| **Störung** | Endlage nicht erreicht nach 3 s | Betroffenen Schieber abschalten, Störmeldung |

## Sicherheit & Erdung

| Maßnahme | Detail |
|---|---|
| Kunststoffrohre | Erden – Kupferdraht spiralförmig außen |
| Erdungsanschluss | Verbindung zum AF14‑Gehäuse |
| Spirorohr | Ist selbst leitfähig (keine zusätzliche Erdung nötig) |
| Funkenschutz | Metall‑ und Holzabsaugung **strikt getrennt** halten |

> ⚠️ **Niemals Metallspäne über die Holzabsaugung führen – Funkengefahr!**
