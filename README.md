# Homelab

Setup and maintenance documentation for my home lab infrastructure.

## Structure

| Directory | Purpose |
|-----------|---------|
| `network/` | Network topology, firewall rules, VLANs, DNS |
| `hardware/` | Server specs, disk layouts, hardware inventory |
| `services/` | Service configs, docker-compose files, deployment notes |
| `maintenance/` | Backup procedures, update schedules, runbooks |
